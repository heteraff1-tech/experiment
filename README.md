# Harness

Интерактивное демо конструктора продуктовых процессов. Сценарий показывает путь от постановки задачи до кликабельного прототипа повторной записи к врачу.

Откройте холст, измените запрос, запустите демо и подтвердите одну из гипотез. Холст поддерживает перетаскивание блоков, соединение выходов со входами и масштабирование. После ревью откроется готовый сценарий записи.

Бриф, метрики, исследования и экраны подготовлены заранее. Правки и история запусков живут в текущей вкладке. Демо использует вымышленные данные и запускается целиком в браузере.

## Локальный запуск

```sh
npm ci
npm run dev
```

## Cloudflare Workers

```sh
npm run build
npm run deploy
```

Для публикации войдите в Cloudflare через `npx cf auth login` или задайте `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID` в окружении.
